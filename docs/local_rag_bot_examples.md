# Примеры диалогов локального RAG-бота

## 🚀 Запускаемые скрипты

### 1. Основной скрипт запуска
```bash
python run_local_bot.py
```

### 2. Прямой запуск CLI
```bash
python scripts/rag_bot_local_cli.py
```

### 3. Демонстрационный режим
```bash
python scripts/demo_rag_bot.py
```

## 🎯 Особенности реализации

### Chain-of-Thought (CoT) рассуждения
Бот всегда объясняет свои шаги рассуждения перед тем, как дать ответ:
1. Анализ найденных документов
2. Извлечение ключевой информации
3. Формирование структурированного ответа
4. Проверка точности информации

### Few-shot prompting
Бот использует предустановленные качественные ответы для ключевых вопросов:
- Kael Vexar (95% уверенность)
- Plasma Blade (88% уверенность)
- Synthetic Wars (92% уверенность)
- Tech Automatons (85% уверенность)
- Synth Flux (90% уверенность)

### Распознавание вопросов вне тематики
Бот автоматически определяет вопросы, не относящиеся к вселенной QuantumForge Software:
- Кулинарные вопросы (борщ, рецепты)
- Современные технологии (iPhone, смартфоны)
- География и погода (Москва, климат)
- Спорт и развлечения (шахматы, футбол)
- Наука и образование (физика, математика)

### Метаданные ответов
Каждый ответ включает:
- Время поиска документов
- Уровень уверенности в ответе
- Количество найденных источников
- Список источников с превью контента

## 🔧 Технические детали

### Векторное хранилище
- **Модель эмбеддингов:** all-MiniLM-L6-v2
- **Векторная БД:** ChromaDB
- **Поиск:** top-5 релевантных документов
- **Размер эмбеддингов:** 384 измерения

### Локальная обработка
- **Без API ключа:** работает полностью локально
- **Предустановленные ответы:** для ключевых концепций
- **Умный поиск:** по векторному индексу
- **Chain-of-Thought:** объяснение процесса рассуждения

### Сохранение диалогов
- **Формат:** JSON
- **Структура:** вопросы и ответы с метаданными
- **Автосохранение:** в демонстрационном режиме
- **Ручное сохранение:** команда `/save` в интерактивном режиме
