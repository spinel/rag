# Векторный индекс базы знаний

## Обзор

Векторный индекс создан для быстрого поиска по базе знаний QuantumForge Software. Индекс позволяет находить релевантные фрагменты текста по пользовательским запросам с высокой точностью.

## Технические характеристики

### Модель эмбеддингов
- **Название**: all-MiniLM-L6-v2
- **Источник**: [Hugging Face Hub](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)
- **Размер эмбеддингов**: 384
- **Устройство**: CPU
- **Особенности**: Быстрая, качественная модель для семантического поиска

### Векторная база данных
- **Тип**: ChromaDB
- **Коллекция**: quantumforge_knowledge
- **Директория**: ./data/vector_index
- **Особенности**: Автоматическое сохранение, поддержка метаданных

### Статистика индексации
- **Всего документов**: 22
- **Всего чанков**: 3,949
- **Время индексации**: 29.36 секунд
- **Размер индекса**: 53.7 MB

### Параметры чанков
- **Размер чанка**: 1000 символов
- **Перекрытие чанков**: 200 символов
- **Сплиттер**: RecursiveCharacterTextSplitter

## Структура базы знаний

База знаний содержит следующие категории:
- **Characters** (10 файлов): Персонажи и их описания
- **Events** (4 файла): События и исторические факты
- **Locations** (2 файла): Локации и места
- **Technology** (6 файлов): Технологии и устройства

## Использование

### Загрузка индекса
```python
from langchain_community.embeddings import HuggingFaceEmbeddings
from langchain_community.vectorstores import Chroma

# Загружаем модель эмбеддингов
embeddings = HuggingFaceEmbeddings(
    model_name="all-MiniLM-L6-v2",
    model_kwargs={'device': 'cpu'},
    encode_kwargs={'normalize_embeddings': True}
)

# Загружаем векторное хранилище
vectorstore = Chroma(
    collection_name="quantumforge_knowledge",
    embedding_function=embeddings,
    persist_directory="./data/vector_index"
)
```

### Поиск по индексу
```python
# Обычный поиск
results = vectorstore.similarity_search("ваш запрос", k=5)

# Поиск с фильтрацией по категории
results = vectorstore.similarity_search(
    "ваш запрос", 
    k=5,
    filter={"category": "characters"}
)
```

### Демонстрация
Запустите демонстрационный скрипт:
```bash
python scripts/search_demo.py
```

2. Запустите переиндексацию:
```bash
python scripts/build_index.py
```
